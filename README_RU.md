# RailPhysics — реалистичная динамика поездов для Workers & Resources: Soviet Republic

Плагин для [tesmioloader](https://github.com/MaxLegend/TesmioLoader),
заменяющий упрощённую физику поездов физической моделью: тяга, торможение,
гравитация, кривые, станции, остановки и расход топлива/энергии — всё
настраивается одним ini-файлом. Ни один файл игры не изменяется: всё
работает как патчи в памяти, установленные лоадером.

Целевая версия: `SOVIET64.exe` **v1.1.1.7** (64-бит). Каждый сайт патча
проверяется по байтам при загрузке: обновление игры просто отключит
затронутую подсистему с записью в лог — плагин никогда не пишет в
изменённый код.

## Что меняется

| Ванилла | RailPhysics |
|---|---|
| Постоянное ускорение `3.61·√(P/5m)` км/ч/с на любой скорости | Тяга `F = min(P/v, μ·W_сцепн·g)`, сопротивление Дэвиса `m(A+Bv)+Cv²` |
| Торможение = разгон / 3, всегда | Независимые нормы торможения (м/с²), мягкое плановое торможение к кривым/станциям/остановкам |
| Гравитация только мешает в гору, спуск нейтрален | Знаковая сила уклона — спуск толкает состав |
| Расход по кривой «скорость/лимит» | Расход по реальной механической мощности `F·v`; холостой ход на стоянке |
| В кривых ограничений нет вообще | Скан маршрута вперёд, `v = √(a_бок·R)` на кривую, тормозная парабола ровно за тормозной путь |
| Через станции — на полном ходу | Зона станции с лимитом (`station_limit_kmh`), вход по тормозной параболе |
| Остановка ударом за 20 м | Парабола до нуля до 25 м, дальше ванильная ползучая рампа |
| Электропоезд ползёт при большом запросе | `grid_boost` умножает потолок оттока электростанций, от которого считается пропускная способность сети |

Старт честный (сцепление режет тягу на трогании); масса состава — вагоны,
груз, пассажиры, износ — берётся из игровых же агрегатов, так что гружёные
2300 тонн и CR400 на 380 тонн — разные вселенные. Скоростной поезд на
хорошем пути берёт 300+ км/ч; тяжёлый состав на 10 % пандусе встаёт и
просит второй локомотив — как в жизни.

## Установка

1. Поставь tesmioloader (лоадер, на котором работает плагин).
2. Скопируй `railphysics.dll` и `railphysics.ini` в
   `<игра>/tesmioloader/build/plugins/`.
3. Запусти игру. В `tesmioloader.log` должно быть
   `8 subsystem(s) patched` и ни одной строки `does not match`.

Удаление: стереть два файла. Сейвы не затрагиваются — плагин меняет
поведение в кадре, в формат сейва ничего не пишется.

## Рекомендуемый компаньон: railspeed

Ванильный лимит пути (150 км/ч бетон) душит всё, что умеет RailPhysics.
Плагин [railspeed](https://github.com/SosseTurner/Railspeed-Plugin-for-Workers-and-Resources)
поднимает **лимит пути** (например, до 330 км/ч) — и ничего больше.
Плагины независимы и дополняют друг друга: railspeed открывает потолок,
RailPhysics заставляет честно его зарабатывать. Не обязателен — без него
всё работает, просто потолок остаётся ванильным.

## Настройка

Всё — в `railphysics.ini` рядом с DLL: каждая подсистема отключается
независимо, в шапке файла задокументированы три проверенных пресета
(строгий реализм / баланс / аркада). По умолчанию — баланс. Главные ключи:

- `power_scale` — аркадный множитель мощности (старт всё равно режет сцепление)
- `curve_lateral_ms2` — насколько кривые душат скорость (0.7 строго … 1.6 аркада)
- `grade_scale` — «крутизна» рельефа (0.06: 10 % пандус — стена)
- `station_limit_kmh`, `smoothstop`, `service_brake_ms2`
- `grid_boost`, `electric_load_scale` — электротяга против сети
- `log_physics`, `log_curves` — телеметрия для калибровки в лог лоадера

Полный справочник ключей — [docs/02-calibration.md](docs/02-calibration.md).

## Сборка из исходников

Linux, llvm-mingw (MSVC не нужен):

```bash
LLVM_MINGW=/path/to/llvm-mingw ./build-linux.sh
```

Результат — в `build/plugins/`. Сам лоадер в проект не входит — только
плагин и вендоренные заголовки его API (`src/tesmio_api.h`,
`src/tesmio_plugin.h`, GPLv3, проект tesmioloader).
