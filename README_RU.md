# RailPhysics — реалистичная динамика поездов для Workers & Resources: Soviet Republic

Плагин для [tesmioloader](https://github.com/MaxLegend/TesmioLoader),
заменяющий упрощённую физику поездов физической моделью: тяга, торможение,
гравитация, кривые, станции, остановки и расход топлива/энергии — всё
настраивается одним ini-файлом. Ни один файл игры не изменяется: всё
работает как патчи в памяти, установленные лоадером.

Что менялось от версии к версии — [CHANGELOG.md](CHANGELOG.md).

Целевая версия: `SOVIET64.exe` **v1.1.1.9** (64-бит) и актуальный
tesmioloader (API плагинов 4). Каждое место патча находится при загрузке по
уникальной сигнатуре байтов и проверяется перед записью: обновление игры
просто отключит затронутую подсистему с записью в лог — плагин никогда не
пишет в изменённый код.

## Что меняется

| Ванилла | RailPhysics |
|---|---|
| Постоянное ускорение `3.61·√(P/5m)` км/ч/с на любой скорости | Тяга `F = min(P/v, μ·W_сцепн·g)`, сопротивление Дэвиса `m(A+Bv)+Cv²` |
| Торможение = разгон / 3, всегда | Независимые нормы торможения (м/с²); плановое торможение к кривым, станциям и остановкам — у грузовых мягче |
| Гравитация только мешает в гору, спуск нейтрален | Знаковая сила уклона — спуск толкает состав |
| Расход по кривой «скорость/лимит» | Расход по реальной механической мощности `F·v`; холостой ход на стоянке |
| В кривых ограничений нет вообще | Скан маршрута вперёд, `v = √(a_бок·R)` на кривую, тормозная парабола ровно за тормозной путь, лимит держится до выхода хвоста; изломы пути (стыки мостов) не тормозят |
| Через станции — на полном ходу | Путь станции — на `station_limit_kmh` от первой стрелки, пока хвост не покинет зону |
| Одни таможни тормозят, другие пролетаются на полной | Таможня — так же, на `customs_entry_kmh`; двухзонная граница — один комплекс |
| Остановка ударом за 20 м | Подъезд к остановке плавный и не медленнее `stop_release_kmh`; останавливает сама игра |
| Длинные вагоны из Workshop опираются на точки в 3 м от концов — колёса съезжают с рельсов в крутых кривых | `bogies`: точки опоры берутся с колёсных пар модели |
| Вагоны в кривых стоят ровно | `tilt`: пассажирские вагоны наклоняются в кривых на скорости (только визуально) |
| Электропоезд ползёт при большом запросе | `grid_boost` умножает потолок оттока электростанций, от которого считается пропускная способность сети |

Все ограничения считаются в метрах маршрута, а не во времени, поэтому
поезда ведут себя одинаково на любой скорости игры. Старт честный
(сцепление режет тягу на трогании); масса состава — вагоны, груз,
пассажиры, износ — берётся из игровых же агрегатов, так что гружёные 2300
тонн и CR400 на 380 тонн — разные вселенные. Скоростной поезд на хорошем
пути берёт 300+ км/ч; тяжёлый состав на 10 % подъёме встаёт и просит
второй локомотив — как в жизни.

## Установка

1. Поставь tesmioloader (лоадер, на котором работает плагин).
2. Скопируй `railphysics.dll` и `railphysics.ini` в
   `<игра>/tesmioloader/build/plugins/`.
3. Запусти игру. В `tesmioloader.log` должно быть
   `10 subsystem(s) patched` и ни одной строки `does not match`.

Обновление с 1.x: замени оба файла — в ini новые ключи, а настройка кривых
теперь в новой шкале (см. changelog). Удаление: стереть два файла. Сейвы не
затрагиваются — плагин меняет поведение в кадре, в формат сейва ничего не
пишется.

## Рекомендуемый компаньон: railspeed

Ванильный лимит пути (150 км/ч бетон) душит всё, что умеет RailPhysics.
Плагин [railspeed](https://github.com/SosseTurner/Railspeed-Plugin-for-Workers-and-Resources)
поднимает **лимит пути** (например, до 330 км/ч) — и ничего больше.
Плагины независимы и дополняют друг друга: railspeed открывает потолок,
RailPhysics заставляет честно его зарабатывать. Не обязателен — без него
всё работает, просто потолок остаётся ванильным.

## Настройка

Всё — в `railphysics.ini` рядом с DLL: каждая подсистема отключается
независимо, в шапке файла описаны три пресета (строгий реализм / баланс /
аркада). Главные ключи:

- `power_scale` — аркадный множитель мощности (старт всё равно режет сцепление)
- `curve_lateral_ms2` — насколько кривые душат скорость (1.7 строго … 3.2 аркада, по умолчанию 2.8)
- `grade_scale` — «крутизна» рельефа (0.06: 10 % подъём — стена)
- `station_limit_kmh`, `customs_entry_kmh`, `stop_release_kmh` — станции, таможни, остановки
- `service_brake_ms2`, `freight_brake_ms2` — плановое торможение пассажирских и грузовых
- `bogies` — ставить длинные вагоны из Workshop на колёсные пары модели
- `tilt`, `tilt_max_deg`, `tilt_gain`, `tilt_min_kmh` — наклон вагонов в кривых
- `grid_boost`, `electric_load_scale` — электротяга против сети
- `log_physics`, `log_curves`, `log_decisions` — телеметрия и журнал решений по каждому поезду в логе лоадера

Рецепты настройки — [docs/02-calibration.md](docs/02-calibration.md).

## Сборка из исходников

С [llvm-mingw](https://github.com/mstorsjo/llvm-mingw) (MSVC не нужен):

```bash
LLVM_MINGW=/path/to/llvm-mingw ./build-linux.sh      # Linux
LLVM_MINGW=/c/path/to/llvm-mingw ./build-windows.sh  # Windows, Git Bash
```

Результат — в `build/plugins/`. `build-windows.sh` дополнительно собирает и
запускает офлайн-стенд (`test/host_test14.cpp`, см.
[docs/03-testing.md](docs/03-testing.md)), если `GAME` указывает на папку игры.
Сам лоадер в проект не входит — только плагин и вендоренные заголовки его
API (`src/tesmio_api.h`, `src/tesmio_plugin.h`, GPLv3, проект tesmioloader).
